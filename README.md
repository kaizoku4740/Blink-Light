# Blink-Light
A 555 LED chaser board project in the shape of a heart made to learn about electronics, schematic design and PCB layout in KiCad
The board lights up 10 LEDs in a sequence to create a rotating pattern that can be adjused with a potentiometer

WHy this was made
I created this product to introduce myself to the world of electronics, and the design was originally intended for mothers day but i forgot that already pased, and with fathers day approaching this will work for that. I positioned the leds along the perimeter of the heart as i thought that would look visually appealing.
